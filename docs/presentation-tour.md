# 新增四区同屏大屏

版本：v0.65.0；日期：2026-10-28。

独立访问 `/display?year=2025`。大屏同时显示四个区域，每个区域自动切换原平台按钮点击后的**完整内容界面**；能源用能分析中的指标、矩阵、企业排名、预算、目标保持为一组，碳排分析的六块内容也一起展示。不会把单个图表拆成一页。

原站顶部栏、分页组件和根样式入口已恢复到 v0.63.2，普通页面没有新增入口或展示参数分支。新增大屏不挂在业务布局内，不挂载重复的小云后台；页面内容和图表复用原组件及原数据库查询，不改原组件实现。

## 播放方式

- 打开即四区同时播放，默认每个完整界面 25 秒，可改成 10、15、25、40、60 秒。各区独立循环，就绪后才计时，一个区加载较慢不阻塞其他区。
- 无需点击平台原有按钮，四区会依次展示上述内容。总览切换时连地图与片区卡一起切换；诊断按原分页按钮自动选择对应的整个分页。
- 长页面整体缓慢滚动，内部长表格与列表也自动滚动，起止留阅读时间；没有抽离、克隆或单独放大某张图表。
- 顶部可暂停/播放全部、统一年份、全屏和查看内容目录。每区底部的圆点、前后箭头切换完整界面并暂停全局播放。
- 每区“放大”只把这个完整区域扩大到当前大屏；“四区同屏”恢复。其他区域保持挂载并暂停，不重新加载。
- 同屏时整组桌面内容等比缩放，适合展示平台概览；需要读细节可放大整个区域，或点击“查看原页”在新标签查看原业务页面。
- 自动切到其他浏览器标签时暂停计时，返回后当前界面从头计时。登录沿用原平台会话，过期时显示登录入口；加载超过 45 秒显示重试/下一界面，不伪造内容。

## 实现边界

`app/display` 是独立路由树；`view/page.tsx` 根据 `lib/presentation.ts` 的白名单导入原服务端页面并传入年份与业务 tab。它不会经过 `(platform)/layout.tsx`，原路由和原导航不用改。

`DisplayScene` 在新的渲染实例中触发原总览片区按钮或诊断分页按钮；待 `aria-pressed` / `aria-selected` 已匹配后才通知父页开始计时。原路由下的这些组件不接收展示参数、不新增轮播副作用。组件布局完整保留，每个 iframe 只有一整个选中界面。四区各自只有一个 iframe，不预挂载所有 25 个状态。

`DisplayScene.module.css` 只绑定新增容器；桌面画布在 iframe 内按正常桌面断点排版，再由父页按区域大小等比缩放。播放器只接受来自同源、当前 iframe 窗口、对应模块和当前状态的消息。非法模块/状态返回 404，原登录守卫仍保护 `/display` 及 `/display/view`。

展示框不接收鼠标或键盘焦点，避免无人值守时跳出大屏或改变查询年份；主动浏览可以通过大屏自身的控制和原页面链接进行。当前不穷举企业详情弹窗、每个月份/年份/排序等所有筛选组合。
