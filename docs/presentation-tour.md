## 使用

- 默认每板块 20 秒，可选 10、20、30、45、60 秒。当前界面播完后进入下一个，名录播完回总览。
- 左侧直接选择界面，下方直接选择板块，均暂停自动播放；点击“开始轮播”继续。方向键切换，空格暂停/播放。
- 点击图表或滚轮浏览会暂停。自动播放时长表格、策略库等从顶部缓慢滚到底部，起止均留阅读时间；手动暂停后可以自由滚动。
- 切到其他浏览器标签时暂停计时，返回后继续自动播放（当前板块从头计时）。年份切换重载整个轮播，统一使用所选年份。
- 全屏按钮扩大整个播放器；“界面目录”可收起侧栏；“返回当前原页面”退出轮播并打开对应业务界面。
- 登录沿用原站会话。会话过期时返回登录；页面加载 45 秒仍未完成会暂停，并提供重试或下一个界面。

## 实现与边界

`lib/presentation.ts` 是前台路由白名单。`/display` 使用同源 iframe，每次只加载一个原界面；参数 `present=1` 启用展示容器及限定样式，不挂载重复的主导航、健康轮询或小云语音。双方只接受来自同源、当前父/子窗口的消息。

展示容器枚举原页面的面板；通过祖先路径和当前板块类名切换可见性，保持 React 组件和图表状态，不搬动或克隆业务 DOM。诊断的 `SectionPager` 在展示参数下挂载所有分页内容，普通访问仍只显示所选分页。地图总览、地图侧板分别参与展示，避免互相遮挡。

每次进入一个界面会执行它原有的服务端查询；在同一界面停留时遵循组件原有刷新机制（例如行情每 60 秒检查）。它不把年度统计变成现场实时采集，也不修改估算、情景预测、指标口径或数据缺口说明。当前仅一条选中对象的定位详情参与轮播，不自动穷举所有企业弹窗。
