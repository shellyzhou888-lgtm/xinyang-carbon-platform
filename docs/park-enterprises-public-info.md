# 信阳经开区企业公开信息

> 整理日期：2026-10-20。来源均为公开网页，每条后注明来源。
> 用途：大屏企业点位和荣誉标识、对象树初始化、后续建企业档案表时作为种子资料。
> 说明：经开区的完整企业名录和规上企业清单需由园区管委会提供；下表以公开报道能确认的企业为准。

## 1. 园区片区构成

| 片区 | 位置 | 说明 |
| --- | --- | --- |
| 绿色家居 | 羊山新区家居小镇（信阳国际家居产业小镇） | 家居小镇规划 15.16 km²，2012 年签约启动；2023 年有近 60 家家具家居制造企业 |
| 电子信息 | 金牛园区（原金牛产业集聚区，浉河区） | 金牛产业集聚区成立于 2009 年，以谷麦光电为代表的电子信息为主导；星原智能被报道为位于“信阳经开区金牛园区电子科技园” |
| 智慧岛、科创部落 | 羊山新区 | 科创研发片区规划用地 2385 亩 |

> 经开区规划总面积约 15.6 km²，与羊山新区实行“双轮驱动”管理（信阳日报 2023-09-19）。金牛片区并入经开区的批复文件还没有找到。
