## 必须先处理的配准问题

M01—M04显示，既有七组团红线中有区域跨在湖面上。项目原资料已说明规划叠加采用两点相似变换初步配准，可能有数百米偏移。这些截图提供了进一步复核的线索，不能仅据截图判断规划错误、违法占湖或现状建筑缺失。

下一轮在权威边界/更多控制点核对前，灰模中的“可辨现状”与“规划示意边界”分别组织对象；不让红线强制裁切湖岸或指挥生成建筑。不能凭两张不同角度截图宣称得到精确摄影测量模型。

## Macro → Micro执行顺序

1. 实拍、卫星截图和既有规划核对，整理可见体块与未知项。
2. 基于以上证据重画概念场景并请用户确认。获确认的图稿才成为SCENE TRUTH，旧v1画稿未通过评审。
3. 全场景一次铺齐大体块、道路、湖面/地形占位、前景、中景、远景。只用中性灰材质，不先精雕单栋。
4. 检查整体空间节奏、疏密、道路连通、留白和镜头遮挡。
5. Structural refinement pass：依据真实参考增加厂房高低跨、主附楼进退、退台、凹口、多翼内院、连廊和屋顶层次。规则厂棚本身应保留合理规则性，变化来自实际附属结构；不做随机扭曲。
6. 补正面/侧面/顶面、比例尺与尺寸依据，形成并确认正交资产图作为ASSET TRUTH，再细化单体。
7. 最后材质、设备、景观、灯光和网页导出预算。真实尺寸缺失时明确标为推定。

Blender MCP连接问题沿用既有记录，当前这轮未执行Blender或输出模型。
