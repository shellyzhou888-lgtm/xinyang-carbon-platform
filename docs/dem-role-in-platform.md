# DEM在本项目中的作用

文档版本：v1.0（2026-10-20）

## 当前状态

ASTER GDEM V3 N32E114已免费下载并裁剪，原始包与GeoTIFF保存在被忽略的 `storage/geography/`。网页后台只展示相对高程图片，提供网格及处理记录下载。地图组件没有请求DEM高程网格，3D按钮仅改变高德相机倾角；ECharts-GL显示的是能耗柱体，均未使用DEM塑造地形。

因此，DEM当前是后续三维地形的预备资料，对现有能耗、碳排放和达标指标计算没有直接作用。

## 用途

DEM保存每个栅格位置的高程。后续可用这些高度构建地形网格，再把卫星影像作为地表纹理贴上去，让三维场景表现园区周边高低起伏；也可为坡度、坡向等地形分析提供基础。开展具体分析前仍需核对坐标、垂直基准、异常值和用途精度。

NASA的[ASTER GDEM V3说明](https://asterweb.jpl.nasa.gov/GDEM.asp)将该产品标为30米间距、1度分幅的GeoTIFF。项目公开网页网格每3个原像元采样一次，约为90米间距的预览网格；原始约30米栅格在本机保留。

## 不能替代的数据

- 规划/法定边界和企业地籍：DEM不包含行政审批或产权红线。
- 厂房三维模型和单体建筑高度：现有栅格不足以恢复厂房屋顶、层数及精细外形。
- 能源与碳核算：本项目目前仍依据企业活动量、统计量、因子及核算规则计算，不以地形代替上述台账。

本次未启用地形渲染或坡度计算，未增加地形业务指标。处理记录见 `apps/web/public/geography/dem-manifest.json`，可复现准备脚本 `scripts/prepare-dem.py`。
