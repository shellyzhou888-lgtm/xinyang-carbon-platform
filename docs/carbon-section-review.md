# 碳排板块内容归类检查

日期：2026-10-28 · 仓库版本：v0.62.1

本次按用户截图检查现有五个碳页签，给出归类与调整建议。碳页面本次保留现有内容和位置，未执行删除或迁移。用户另外明确要求能效对标固定一屏，该排版调整已单独实施。

## 主要结论

“排放预算使用”与减排管理有间接关系：它说明年度排放总量的额度和进度，不能直接回答采取哪些措施、由哪家企业实施、预计减少多少排放。它更适合作为“排放分析”中的总量控制卡。减排管理建议形成“指标目标 → 企业措施 → 情景路径”，比当前“指标 → 预算仪表 → 情景”更贴合页面名称。

顶部四项 KPI 为跨页共享园区背景，不属于业务卡片的重复删除对象。产品轨迹已有固定示例年份、功能单位及模拟物料说明，不能把园区筛选年份自动当作产品模型重算年份。

## 建议的下一步布局

- 排放分析：总量趋势、排放构成、企业贡献与优先级、年度变化、年度预算。
- 产品碳足迹：左侧上下两条完整轨迹，右侧各链热点。
- 碳流网络：左侧地图，右侧企业数值辅助区。
- 减排管理：左侧指标目标，中间企业减排措施，右侧情景路径；与综合诊断保持跳转。
- 碳资产：敞口、措施金额价值、价格趋势、最新行情。

现有 `CarbonManagementData.plans` 已提供企业、关联问题、策略、预计节能量、预计减排量与模拟参数标记，可支撑中间的措施清单。它目前是按所选年度未关闭问题关联的策略建议，不能直接显示为已完成项目。现有数据未提供完整责任人、计划期限和实施进度，后续如需项目执行管理，应补充这些字段后再展示。
