## 身份与区位处理

- 信阳高新区、平桥产业集聚区和全市企业名单不整体并入本经开区。
- “信阳永豪轩家具有限公司”与“河南永豪轩智能家居股份有限公司”分别保留，未取得主体变更凭证前不合并；现POI不绑定旧法人模拟能耗。
- 亚丹按省政府报道保留“亚丹生态科技（信阳）有限公司”正式名称。供应商目录正文与标题出现的“家居/家具”差异不自动生成两个公司。
- “颂德/领德”标题与正文不一致，保留待核条目，不绑定地图。
- 欧缇丽官网确认“材料科技发展有限公司”全称，目录已采用全称；2023年调研报道的简写仍在来源中留痕。
- 左右鑫室依2026年法院公告转入历史企业，目录保留以解释旧资料，不列作当前企业。
- 左右鑫室、德胜、诺源、欧缇丽、勤拓5个新增POI只有位置，不编造能耗。匹克与物流项目没有可靠对应厂区POI时不将门店或集团办公点当作生产基地。

## Logo

万华、谷麦、现代筑美、亚丹、百德、天一及本次新增的凯源水务原图保存在本项目公开素材目录，各自来源URL、下载URL、历史版本说明见 `apps/web/data/enterprise-branding.json`。目录页对每个有核验Logo的条目展示原图，不再限定“重点展示”。现代筑美、亚丹部分标识为历史公开版本。欧缇丽官网本次取得的图片实际仅为纯色矩形，已弃用；其余企业没有可靠素材时留空，不使用近名公司标识。凯源白色标识在目录页使用深蓝色底。

地图只为公开重点展示企业且有可靠Logo的条目加载Logo标签；所有POI仍可通过列表选择。Logo碰撞会避让；选中企业提升显示优先级。

网页入口 `/enterprises`，支持企业名/产业搜索、片区与类型筛选、仅重点展示筛选、来源链接和已绑定POI的地图定位。
