# 数据清单（天气数据更新至 2026-10-21；其余业务数据沿用 2026-10-20 核查）

> 数据库：`greensystem`。能耗、统计等业务事实数据带来源标记 `data_source`：
> - `manual` 和 `measured` 为真实数据；
> - `estimated` 为模拟估值，即 AI/规则生成的占位数据。
>
> 模拟数据在真实数据导入后会被自动替换，旧值保留为历史；反之，模拟数据不会覆盖真实数据。

### 2.5 外部天气与辐照（2026-10-21，迁移 0028）

NASA POWER 使用 WGS84 114.12°E、32.22°N 附近网格；12 项直接取日值，降水由小时数据完整 24 小时求和，13 项合计 27,207 条。缺测 `-999` 不入标准化表；曾出现的 24 倍降水异常已根据小时数据重算，一天的小时异常另用 NASA 单日响应校核，现有质量标记均为 `ok`，原始响应保留。高德使用平桥区行政编码 `411503`，保存实况发布时间及每版短期预报。数据分存 `fact.weather_daily`、`fact.weather_hourly`、`fact.weather_live` 和 `fact.weather_forecast`；它们不是企业或园区现场的实测能耗。同步细节见 [数据 API 接入说明](data-agent-and-api-assessment.md)。

NASA POWER 小时值另存 `fact.weather_hourly`，使用明确的 UTC 时间戳；2026-10-21 实测已回填 2021-01 起 398,976 条，8 个参数均无 `suspect`。辐照与云量最新有效小时为 2026-07-31 23:00 UTC，温度、湿度、风速、降水为 2026-10-19 23:00 UTC。其太阳辐照小时单位为 `Wh/m²`，不应直接当作瞬时 `W/m²` 或分钟级观测。

### 值得注意的几点

1. **能源类核心指标在模拟数据下未达标。**
   - 能源产出率低，主要是因为万华人造板产值占比大、能耗强度高（约占园区能耗的六成）。
   - 可再生能源占比低，是因为模拟的光伏规模相对园区能耗太小。
   - 这些都是按行业强度模拟的结果，没有为了达标去调整假设。真实数据到位后才能判断。
   - 如果需要演示用的达标效果，可以另建一套“演示场景”的假设文件，例如提高光伏装机或绿电比例，作为独立批次导入并明确标注，不与当前模拟数据混用。
2. **单位能耗 CO₂ 偏高（3.44）。** 原因是电力按当量值 0.1229 kgce/kWh 折标，电力每 tce 对应约 4.8 tCO₂；零碳园区口径要求电力按等价值折标，补齐电力等价值后，这个比值会明显下降。
3. **展示数量**：前台达标展示视图当前返回 2026 版 6 项（2025 年）、2024 版基线 7 项（2023 年）、零碳园区引导指标 2 项。

## 六、如何替换为真实数据

1. 园区或企业按 `templates/` 中的模板填写，“数据来源”选真实来源（计量表实测、手工台账、统计报表、公开报道等）。
2. 导入：

   ```bash
   cd packages/ingest
   npm run ingest -- 文件.xlsx --template 模板编码
   ```

   同一企业、同一期间、同一品种的模拟值会被自动替换，旧值保留为历史。
3. 重新计算：

   ```bash
   npm run calc -- --version GIP_2026 --node XYEDZ --year 2025
   ```

4. 查询某项指标中模拟数据的占比：`fact.indicator_value.estimated_share`。占比为 0 表示该指标完全基于真实数据。
