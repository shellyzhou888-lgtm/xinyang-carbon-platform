## 已核实的资料范围

生态环境部于 2026-03-01 [发布第二版](https://www.mee.gov.cn/ywgz/ydqhbh/wsqtkz/202603/t20260301_1145117.shtml)：总计 576 个因子，新增和更新 291 个，覆盖能源活动、工业生产过程、农业活动的直接排放因子，以及电力消费间接排放因子，并纳入粗钢、未锻轧铝等重点产品碳排放强度。公告说明可在因子库查询和参考使用，但没有给出单条因子的名称、数值、单位与适用条件。

本次直接访问因子库时返回 HTTP 412，浏览器页面为空；因此下表的“可用”指**值得从该库逐项取证的资料类别**，并不代表对应数值已经复核。

## 与现有平台的对应关系

| 优先级 | 因子资料 | 项目对应位置与用途 | 取用前的核对重点 |
| --- | --- | --- | --- |
| 高 | 电力消费间接排放因子 | `ELEC_GRID`；绿色工业园区按河南省电力平均因子，零碳园区按全国化石能源电力因子；现存 2021–2023 年数据及年份回退逻辑 | 明确统计年度、地区、平均/化石电力等口径，以及绿电处理规则；不能仅凭“电力因子”名称覆盖现有值 |
| 高 | 化石燃料燃烧因子与低位热值 | `NATURAL_GAS`、`DIESEL`、`RAW_COAL`、`GASOLINE`、`LPG` 等；补齐当前仅有草稿或缺批准值的品种 | 行业/设施类别、煤种、气体种类、是否包含氧化率、原始与换算单位；区分缺省值和实测值 |
| 中 | 外购热力相关因子 | `HEAT_FOSSIL`、`HEAT_NONFOSSIL`；与现行 910 号文热力口径对照 | 热源类型、是否已有实测值，以及标准规定的优先顺序；不能把电力因子用于热力 |
| 中 | 工业生产过程及非 CO₂ 气体 | 企业碳核算后续扩展，可能涉及工艺排放、CH₄、N₂O 等 | 当前 `fact.energy_activity`/`core.factor` 以能源和 CO₂ 为主，须先确认园区企业真实工艺，再扩展活动数据、气体种类、GWP 与核算边界 |
| 低 | 重点产品碳排放强度 | 将来产品碳足迹或供应链模块的对标资料 | 粗钢、未锻轧铝等产品强度不能代替园区或企业能源活动排放因子；先确认企业产品是否匹配 |
| 低 | 农业活动因子 | 目前园区主业和平台核算范围没有明确对应场景 | 有实际农业活动与核算需求时再纳入 |

## 已发现的口径差异

[JS/T 303—2026《公共机构碳排放核算指南》附录 A.1](https://www.ggj.gov.cn/tzgg/202603/P020260323391227168041.pdf)注明，其燃料燃烧因子引自国家因子库中“其他行业 → 公共建筑运营单位 → 燃料燃烧 → 化石燃料燃烧”的最新发布值。该表列出天然气 **56.1 tCO₂/TJ**、柴油 **74.1 tCO₂/TJ**，并分别给出便于公共机构使用的单位换算值。项目目前批准的是依据生态环境部钢铁行业核算指南附表 A.1 参数计算的天然气 **55.6116 tCO₂/TJ**、柴油 **72.5853 tCO₂/TJ**（见迁移 `0010`、`0012`）。两组数值的适用对象和参数来源不同；应在确定本园区企业所属行业和对应评价标准的核算规则后，逐项比较并保留来源、版本和口径，不能直接互相替换。该公共机构文件也要求优先采用适用的国家因子库因子，并对热力列出条件性的 0.11 tCO₂/GJ 缺省值；这可作为园区公共建筑场景的参考，不自动扩展到所有工业企业。

## 建议的接入顺序

1. 在因子库可访问时，先导出或逐条保存电力、天然气、柴油、煤、汽油、液化石油气及热力的详情，记录**因子名称、值、单位、温室气体、行业/设施、地域、适用年份、发布版本、原始链接或文件**。
2. 将候选值与 `core.factor_source`、`core.factor` 和 `core.standard_version.factor_preferences` 对照。新值先记为 `draft`，标明审查人和差异原因；完成标准适用性复核后再批准。不要把本次网页不可访问当作数值确认。
3. 优先补齐当前未批准的常见燃料，再考虑工艺排放和其他温室气体。后两类需要扩展数据模型及核算逻辑，不能仅增加一条 `core.factor`。
4. 保留原公告或详情快照，按版本和适用期管理更新；核算结果保存所选因子及来源，便于历史结果复算和审计。
