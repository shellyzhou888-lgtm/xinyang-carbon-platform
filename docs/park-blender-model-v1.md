# 四区 Blender 首轮模型 v1

后续进展：已按用户要求完成[四园区完整概念组装v2](park-full-assembly-v2.md)，包括四个独立工程、完整GLB、道路、院区与景观配套。本页保留首轮代表资产与样区的制作记录。

2026-10-22，用户确认“我觉得可以，你可以开始建模，色调需要统一”。本轮采用四区场景概念 v2 和建筑概念 v1 作为获准的场景／资产设计依据；原 v1 场景图仍是未通过的历史稿。

交付入口：[模型、配色与渲染目录](../assets/blender-models/v1/index.html)。这是四个参考驱动的**场景研究样区**和四类代表建筑的首轮建模，不是全部园区逐栋实测复原；建筑数量、道路布局和尺度不具备测绘精度，也没有绑定企业能碳数据。

## 制作顺序与 MCP 证据

1. 实际安装官方 Blender 4.5.9 LTS Windows 便携版，核对官方下载 SHA-256；安装 `ahujasid/blender-mcp` 上游发布的 `mcp-for-blender==2.2.2` 插件及服务端。
2. 在真实 Blender GUI 进程中启用插件，仅通过本机环回地址连接。启动脚本只负责启用 MCP 桥接，没有建模代码。未使用离线 bpy、Blender 后台 CLI、直接 socket 指令或其他建模器创建模型。
3. 当前对话未热加载新的原生工具命名空间，因此使用官方 Python MCP SDK `ClientSession` 经 stdio 完成 initialize、tools/list、tools/call，调用上游真实工具 `execute_blender_code`。客户端见 [blender-mcp-client.py](../scripts/blender-mcp-client.py)，全部场景源代码见 [scripts/blender](../scripts/blender)。关闭遥测，开启服务端 safe mode，不使用付费生成或外部资产服务。
4. 首先铺齐四区所有大体块、道路、前景／中景／远景、湖面及空地，保存灰模，输出四张灰模检查图。修正底板与地面共面及镜头裁切，整体检查后才进入结构细化。
5. structural refinement pass 加入有参考类型依据的多跨屋顶、附楼、高低跨、退台、楼梯核、裙房与廊道。家居代表资产统一为四跨屋面，解决生成板跨视图数量不一致；没有随机扭曲建筑。
6. 之后加入门窗、金属板接缝、装卸雨棚、设备、排水管、院落廊柱、台阶及道路标线，共享同一套材料。通过 MCP 完成全部 `.blend` 保存、Cycles 渲染及 `.glb` 导出。每次工具返回记录汇总于交付目录 `mcp-audit.json`。

## 统一配色

| 用途 | sRGB 色值 | 处理 |
| --- | --- | --- |
| 建筑主体 | `#DAD9D0` | 暖灰白，四区共用 |
| 金属屋面 | `#AEB7B7` | 浅蓝灰，低反射 |
| 玻璃 | `#58737C` | 低饱和蓝灰，首轮为不透明简化玻璃 |
| 基座及构件 | `#535D60` | 深灰 |
| 工业识别色 | `#914F48` | 少量装卸门、雨棚边，避免大面积艳红 |
| 庭院木构 | `#8E7860` | 灰棕色 |
| 草地／树木／水面 | `#87947C`／`#5F755F`／`#6F9090` | 降低饱和度，与建筑统一 |

材质以 sRGB 转线性写入 Blender，glTF 按标准色彩空间导出。四区使用相同的太阳、环境光与 AgX 设置；树木为低面代理，植被和地面目前没有照片级纹理。

## 资产与位置限制

| 文件代号 | 内容 | 依据与限制 |
| --- | --- | --- |
| GH | 家居多跨厂房样区与代表资产 | S04-04、M12；门窗、附楼与尺度为参考驱动推定，非现代筑美精确复原 |
| EI | 电子车间样区与代表资产 | S21-01、S21-05、M17、M19；长条车间、雨棚和多翼楼类型研究 |
| IN | 北湖低密度湖岸样区与院落单元 | S39-04、S34-05、M01–M04；院落是批准的新设计提案；不按可能落水的规划红线切割岸线 |
| RD | 部分开发的研发片区样区 | M05–M07；保留道路、空地和少量楼群，不以未核实塔楼填满场地 |
| RA | 羊山智慧岛主楼、裙房与侧翼独立资产 | S32-08正面照片；背面、屋顶和尺寸待核；不表示已核实其位于RD地块 |

模型统一米制。总工程内样区分开展示，各GLB在导出时移回自身局部原点，使用glTF标准Y向上；没有将GCJ-02经纬度直接写成米，也没有声称完成地理配准。下一轮地图挂接前仍需用真实建筑轮廓、道路控制点和高度核准位置与比例。

打开完整工程后，可在Blender顶部Scene下拉中选择五个命名场景，分别查看四区样区与独立资产；它们共享网格数据。默认场景显示绿色家居，避免初次打开时所有样区叠在一个远景里。

正交图由**同一套三维网格的真实正交相机**渲染，属于本轮资产的几何一致性检查；它们不会把推定尺寸变成测量事实。全景为样区，单体近景用于看建筑细节。现场材料纹理、复杂工艺管网及逐栋实测精修留待进一步资料核验。

## 本地连接复用

本机便携程序位于被Git忽略的 `storage/tooling/blender-mcp/runtime/blender-4.5.9-windows-x64/blender.exe`。启用插件后，运行MCP客户端传入 `--library scripts/blender/common.py --code <脚本> --label <记录名>`；环境须有uv/uvx及MCP Python SDK（`mcp<2`）。不要直接执行场景脚本或使用Blender CLI制作模型。

上游来源：[Blender官方下载目录](https://download.blender.org/release/Blender4.5/)、[MCP for Blender项目](https://github.com/ahujasid/blender-mcp)。安装程序、第三方源文件及本机日志不上传仓库；工程、模型、制作脚本、审阅图及可核验的工具结果清单上传本项目GitHub。
