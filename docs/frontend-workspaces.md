# 前端工作区实现与验收

文档版本：v1.2（2026-10-21）

## v1.2 视觉与结构重做（2026-10-21）

参考用户提供的伊利碳管理大屏、Eaton EPMS 与高密度 SaaS 界面，统一为“无线框”深色玻璃质感：卡片不画边框，靠底色明度、背景模糊与间距区分层次；强调色为青柠绿 `#c5f05c`，能源用翠绿、碳用琥珀色，数字使用 Bahnschrift/DIN 等宽数字字体。

| 部分 | 做法 |
| --- | --- |
| 登录页 `/login` | 左侧以规划四片区与15个企业点位绘制的线稿动画（与地图同一套示意几何，非法定边界），右侧登录卡片；不使用版权未明的园区照片 |
| 路由保护 | `proxy.ts`（Next 16 的中间件）校验 `xy_session` 签名 Cookie；页面跳转登录，接口返回 401。账户来自 `apps/web/.env.local` |
| 外壳 | 左侧图标导航条（总览/能源/碳管理/诊断/名录/后台）+ 顶栏（连接状态、年份切换、时钟、用户与退出）；数据助手改为右侧滑出抽屉 |
| 总览 | 卫星地图铺满舞台，能源（左）与碳（右）为悬浮玻璃面板，片区切换在顶部居中，地图工具与边界说明在底部；企业列表与企业详情为悬浮卡片。下方为近三年趋势与达标概览（只显示已达标数量，不显示未达标） |
| 业务页 | 统一为 KPI 行 + 分段页签 + 分栏面板；诊断改为四步步骤条 |
| 图表 | `lib/chart-theme.ts` 统一配色、渐变面积、无轴线、玻璃提示框 |
| 动效 | 选用 motion（motion.dev）：页签/年份/导航的滑动高亮、悬停、抽屉进出、数字滚动。页面与卡片入场改为 CSS 关键帧，保证未执行脚本时服务端内容也可见。未引入依赖 Tailwind 的 Kokonut UI / Bklit UI；anime.js 与 motion 功能重叠未引入 |
| 连接状态 | `GET /api/health` 返回数据库延迟与模型 Key 是否配置；浏览器另行探测小云后台 |

页面路由移入 `app/(platform)/` 路由组（URL 不变），登录页不套用平台外壳。

## 页面结构

对应《平台架构与指标体系》5个主模块，使用共享导航和统计年选择。没有新增独立的“指标与达标”前台页；达标结果融入业务，定义和公式在后台管理。

| 主模块 | 路由与内容 |
| --- | --- |
| 园区总览 | `/`：能源汇总、卫星定位叠加规划分区、碳汇总、近三年月度趋势、公开认证荣誉；仅展示已达标指标 |
| 能源管理 | `/energy`：能源消费、可再生能源、能源强度、能流网络4个页签；预算对比、ECharts-GL企业能耗、按能源单位分组的桑基图 |
| 碳管理 | `/carbon`：排放分析、碳流分析；核算规则弹窗、预算、排放结构/强度/企业贡献；碳市场和产品碳足迹无值时明确留空 |
| 能碳综合诊断 | `/diagnosis`：预警、根因、策略、预测4步；预警默认待处理，可查看历史；月份/贡献表代替JSON；预警关联策略有模拟节能量和减碳量；最新情景路线图和月度预测 |
| 后台管理 | `/admin/data` 数据来源和因子/地形资料；`/admin/indicators` 4版指标配置只读查看；`/admin` 沿用原治理审核功能 |
| 企业资料 | `/enterprises`：总览附属名录，不作为第6个业务主模块；22条公开记录，搜索/筛选/出处/定位 |

共享布局 `PlatformShell` 保留各页面与页签的年份参数，助手挂载一次。文字对话按需展开，Escape关闭后还原焦点；打开对话时避免语音形象遮挡。语音切换年份保留当前业务路由与页签。吸碳云朵GIF沿用前次成果，不变更语音后端协议。

## 地图取舍

用户最新决定不需要OSM要素，已经从页面移除试验图层及入口。原WGS84研究资料仍保留在仓库，转换与界面试验留在忽略的本机研究档案，没有加载到生产页面。

卫星定位直接叠加规划四区10个面（科创部落7个分散组团），面积按原规划图引用。独立规划视图和原图对照已移除；图像像素轮廓通过两个人工对应点初步定位到GCJ-02，未经独立精度校核，可能存在偏移，不作为26号文法定界址或企业红线。控制来源和坐标假设写入注册清单。

3个预设、15个公开POI、重点品牌Logo及企业列表保留。规划分区开关控制边界和名称。企业分布包络开关已移除，未加载OSM要素。

## 数据接入与限制

- 新增 `getManagementData`、数据来源/因子清单和指标配置的固定只读SQL，沿用现有数据库连接与计算口径，无数据库结构变更或写入。
- 读取另一会话已经提供的 `getCarbonManagementData`，未修改其数据层。预算、策略、储能和路线图包含模拟参数，页面保留演示标识。路线图读取最新批次，不随年份伪造新模型。
- 能流按品种和单位分别绘图，避免把kWh、m³、GJ相加；模拟内部层级分摊不是新增园区能耗。碳流未建立独立闭合换算，保留明确空状态。
- 指标页面是定义/公式只读查看；数据页是来源与接入说明，尚无网页上传或实时采集表单。未把说明页面称为已完成的生产数据接入。
- 地形数据已免费下载及裁剪，但尚未挂载3D地形网格；高德倾斜视图与ECharts-GL柱图不能称为真实三维园区建模。
