# 前端工作区实现与验收

文档版本：v1.0（2026-10-20）

## 页面结构

对应《平台架构与指标体系》5个主模块，使用共享导航和统计年选择。没有新增独立的“指标与达标”前台页；达标结果融入业务，定义和公式在后台管理。

| 主模块 | 路由与内容 |
| --- | --- |
| 园区总览 | `/`：能源汇总、规划分区/企业卫星定位、碳汇总、近三年月度趋势、公开认证荣誉；仅展示已达标指标 |
| 能源管理 | `/energy`：能源消费、可再生能源、能源强度、能流网络4个页签；预算对比、ECharts-GL企业能耗、按能源单位分组的桑基图 |
| 碳管理 | `/carbon`：排放分析、碳流分析；核算规则弹窗、预算、排放结构/强度/企业贡献；碳市场和产品碳足迹无值时明确留空 |
| 能碳综合诊断 | `/diagnosis`：预警、根因、策略、预测4步；预警默认待处理，可查看历史；月份/贡献表代替JSON；预警关联策略有模拟节能量和减碳量；最新情景路线图和月度预测 |
| 后台管理 | `/admin/data` 数据来源和因子/地形资料；`/admin/indicators` 4版指标配置只读查看；`/admin` 沿用原治理审核功能 |
| 企业资料 | `/enterprises`：总览附属名录，不作为第6个业务主模块；22条公开记录，搜索/筛选/出处/定位 |

共享布局 `PlatformShell` 保留各页面与页签的年份参数，助手挂载一次。文字对话按需展开，Escape关闭后还原焦点；打开对话时避免语音形象遮挡。语音切换年份保留当前业务路由与页签。吸碳云朵GIF沿用前次成果，不变更语音后端协议。

## 地图取舍

用户最新决定不需要OSM要素，已经从页面移除试验图层及入口。原WGS84研究资料仍保留在仓库，转换与界面试验留在忽略的本机研究档案，没有加载到生产页面。

默认规划分区根据原图像素描绘4个功能片区，共10个多边形（科创部落7个分散组团）。这不是地理配准后的经纬度边界；原图标注面积直接引用，不根据像素多边形测算。可用原规划底图对照。正式界址仍以26号文成果为准。

卫星定位保留高德/L7、3个预设、15个公开POI、重点品牌Logo及列表搜索，企业分布包络默认关闭。定位关系与企业身份存在差异时不绑定能耗。未取得可靠Logo时不替用其他近名企业。

## 数据接入与限制

- 新增 `getManagementData`、数据来源/因子清单和指标配置的固定只读SQL，沿用现有数据库连接与计算口径，无数据库结构变更或写入。
- 读取另一会话已经提供的 `getCarbonManagementData`，未修改其数据层。预算、策略、储能和路线图包含模拟参数，页面保留演示标识。路线图读取最新批次，不随年份伪造新模型。
- 能流按品种和单位分别绘图，避免把kWh、m³、GJ相加；模拟内部层级分摊不是新增园区能耗。碳流未建立独立闭合换算，保留明确空状态。
- 指标页面是定义/公式只读查看；数据页是来源与接入说明，尚无网页上传或实时采集表单。未把说明页面称为已完成的生产数据接入。
- 地形数据已免费下载及裁剪，但尚未挂载3D地形网格；高德倾斜视图与ECharts-GL柱图不能称为真实三维园区建模。
