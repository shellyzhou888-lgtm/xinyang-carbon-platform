## 2. 诊断板块重构：碳分析 → 碳预警 → 碳评价 → 能耗优化

现有诊断四步是“诊断预警 → 根因溯源 → 减碳策略 → 能碳预测”。建议改为：

1. **碳分析**：根因溯源（企业贡献、变化归因瀑布图、四象限）。碳排页保留“看现状”，诊断页负责“找原因”，图表不重复，只放链接。
2. **碳预警**：保留现有预警分类、风险分布和明细。
3. **碳评价**（新）：GIP_2026 全部 19 项指标逐项给出达标 / 未达标、与引领值的差距和改进路径（例如“可再生能源利用率差 12.2 个百分点 ≈ 需新增绿电 X 万 kWh”）。这是园区内部管理视图，可以显示未达标项；首页和对外展示仍只放达标项。
4. **能耗优化**：策略库、测算和报告保留，并新增“优化组合”：在给定投资预算或减排目标下，从关联策略中挑出减排最多的组合（整数规划或贪心排序）。需要各策略的投资与运行成本，目前缺这一数据；没有成本时按“单位节能量”排序，并给出边际减排成本曲线的数据要求。
5. **效果检验**：能碳预测和减碳路线图作为第 4 步的子视图，显示采用优化组合后的情景曲线。

## 3. 碳核算模型：要不要外部模型

| 层级 | 标准 | 现状 | 是否需要外部模型 |
|---|---|---|---|
| 园区 / 企业温室气体核算（范围一 + 二） | 发改环资〔2025〕910号附件4、GB/T 32150 及行业指南 | `engine` 函数 + 因子库已闭环 | **不需要**。需补：过程排放活动数据；电力因子按生态环境部最新全国电网平均因子更新（服务器已有 2023、2024 年因子文件，人工审核后入库） |
| 产品碳足迹 | GB/T 24067-2024 / ISO 14067 | 只有参考值对标 | **需要**：LCA 计算引擎 + 背景数据库 + 特征化方法 |

建议的外部模型组合：

- **计算引擎**：Brightway 2.5（开源 Python LCA 框架），作为离线计算工具放在 `packages/lca`，读取天工 ILCD/TIDAS JSON，按矩阵法计算摇篮到大门结果，修正天工“全站递归”中出现的异常放大。也可用服务器上已有的 `tidas-0.3.4` 工具做格式转换。
- **特征化方法**：天工自带的“气候变化（IPCC 100 年基准模型）”。
- **结果回写**：计算结果写入数据库，网页只读结果，不在网页里做 LCA 计算。

## 4. 服务器上的天工数据评估

位置：服务器 `D:\10.19数据集\carbon databases\02_碳足迹\`

| 目录 | 内容 | 用途 |
|---|---|---|
| 01_天工_LCI清单 | 5,572 个 ILCD 过程数据集（JSON），按地区分（中国 1,997 个、全球 2,248 个），附投入产出总清单 | 背景数据库主体 |
| 02_天工_严格版碳足迹 | 5,573 个过程的一级供应链 / 全站递归碳足迹，带闭合状态与供应商覆盖率 | 快速筛选；只用“完整闭合”的结果 |
| 03_天工_别名映射版 | 别名规则与映射后结果 | 中文名称匹配 |
| 05_LCA方法与因子 | 25 个 LCIA 方法（含气候变化） | 特征化因子 |
| 01_碳排放因子（同级目录） | IPCC EFDB、CPCD 产品库与企业因子库、生态环境部指南、2023/2024 电力因子 | 组织核算因子与产品对标 |

数据质量（严格版）：完整闭合 1,922 个、部分闭合 3,279 个、无供应商 349 个、无有效结果 22 个。

与园区产品相关的条目存在三个问题：

1. **功能单位多为“1 reference unit”**，不是 m³ 或 kg。例如“定向刨花板（OSB）”为 0.05 / 参考单位，而 CPCD 参考值为 552 kgCO₂e/m³，二者不能直接比较。
2. **多数为部分闭合**，供应商覆盖率 25%–75%。
3. **个别全站递归结果明显异常**，例如“单晶硅片”177,070 kgCO₂e/kg。

可直接使用的主要是完整闭合的通用过程：电网输配、交流电网、天然气开采、电力铁路运输，以及部分化工和金属材料。因此天工的定位是**上游背景数据**，不是园区产品的成品足迹。

### 入库方式

- 新建 `lca` schema（遵守“新表放 lab 或业务 schema、写 COMMENT”）：
  - `lca.process`：过程，含地区、年份、功能单位、闭合状态、覆盖率、来源版本 20261019。
  - `lca.exchange`：投入产出明细。
  - `lca.flow`：物质 / 能量流。
  - `lca.result`：引擎计算结果。
- 通过导入批次记录（`raw.import_batch`）入库，入库后跑语义治理。
- **只有人工批准的背景因子**才能进入产品足迹计算，沿用“因子与足迹审批由人完成”的规则。

## 5. 产品碳足迹与“园区产品全生命周期 / 碳轨迹”可视化

### 试点链条（园区内真实上下游）

- **家居链**：万华禾香“无醛秸秆刨花板” → 园区家居企业（现代筑美、百德门业、永豪轩、天一美家、德胜家居等）的定制家具 / 木门，诺源涂料提供涂装材料。
- **电子链（待核实上下游关系）**：若邦电子材料 → 今上半导体 → 谷麦光电等。

### 核算边界

- 第一阶段：**摇篮到大门**（原料获取、运输、园区生产、包装）。
- 第二阶段：延伸到园区内下游加工，再到使用和废弃（摇篮到坟墓）。

### 计算式（每个功能单位，如 1 m³ 板材、1 樘木门）

```
产品碳足迹 = Σ 原料用量 × 原料背景因子（天工 / CPCD，已批准）
          + Σ 运输量(t·km) × 运输因子
          + 企业范围一+二排放 × 该产品分摊比例 ÷ 产品产量   ← 园区数据库已有
          + 包装与辅料
```

### 需要企业补的数据（新增 Excel 导入模板）

| 数据 | 示例 | 现状 |
|---|---|---|
| 产品目录与功能单位 | 无醛秸秆刨花板，m³ | 部分 |
| 产品产量（年 / 月） | 76 万 m³ | 仅万华 1 家 |
| 物料清单 BOM | 每 m³ 秸秆 x kg、MDI 胶 y kg | 无 |
| 运输 | 秸秆收集半径 km、车型 | 无 |
| 多产品企业的分摊依据 | 产量、产值或工时 | 无 |

### 页面设计（放在“碳排管理 → 碳资产 → 产品碳足迹”，或升级为独立子标签）

1. **产品卡片轮播**（同图 3）：产品图、名称、碳足迹 kgCO₂e/单位、核算日期、数据质量等级。
2. **生命周期阶段条**：原料 → 运输 → 园区生产 → 包装 → 出厂 → 下游加工 → 使用 → 废弃。每段显示 kgCO₂e 与占比，标出热点阶段。
3. **园区碳轨迹图**：在园区地图上沿产业链连线（万华 → 各家居企业），每到一家企业显示“累积碳足迹”增加了多少，直观看到一张板材变成一扇门的碳积累过程。
4. **对标与情景**：与 CPCD 或天工同类参考值对比；情景滑块（绿电比例、MDI 用量、运输距离）实时显示足迹变化。

### 新数据表

- `core.product`：产品目录。
- `core.product_bom`：物料清单，带版本。
- `fact.product_footprint`：结果，带阶段拆分、方法、背景因子版本和数据质量，走导入批次，修正时新增一行。

## 6. 能流 / 碳流优化

### 现状问题

- 地图 + 3D 弧线 + 企业卡片 + 预警光罩 + 右侧三层节点列表，同时表达位置和流量，信息过载。
- 能流和碳流是两套页面，结构几乎一样。

### 改为一个“能碳流向”视图

- **主图：桑基图**，四列：
  1. 能源来源：电网电力、绿电交易、自发光伏、天然气、外购热力、柴油。
  2. 产业片区：4 个。
  3. 重点企业：前 8 家 + 其他。
  4. 去向：能源模式为生产用能；碳模式为范围一 / 范围二。
- **能 / 碳切换**：同一结构，宽度分别为 tce 和 tCO₂。切到碳模式时绿电、光伏的流几乎消失，直观体现“用能增长但碳没有同比增长”。
- **交互**：点企业高亮其完整路径，右侧只显示 3 个数（总量、占比、强度）和同比；顶部年份切换。
- **地图降级**：降为右下角小定位图，点击企业时闪烁其位置。也可以完全去掉。
- **数据**：已有 `getEnterpriseEnergyMix`（企业 × 能源品种的 tce 与 tCO₂）和片区归属，无需新数据。
- **页面调整**：能源页“能流网络”和碳排页“碳流网络”合并为同一组件；企业 → 厂区 → 产线的内部转供桑基图保留为二级视图。

## 7. 模拟数据调整（呈现向好趋势）

### 现状（全部为模拟值，仅 3 条产值为手工录入）

| 指标 | 2021 | 2025 | 问题 |
|---|---|---|---|
| 碳排放 tCO₂ | 99,475 | 288,428 | 4 年增至 2.9 倍 |
| 单位增加值 CO₂ tCO₂/万元 | 1.61（2023） | 1.62 | 三年基本持平 |
| CO₂ 排放弹性系数 | — | 1.35 | 大于 1：排放增速高于产值增速 |
| 可再生能源利用率 | — | 2.76% | 引领值 15% |
| 能源产出率 | — | 2.12 万元/tce | 引领值 3 |

### 目标情景“绿色转型”（数值待你确认）

- 工业产值保持增长，年均约 10%，保留现有经济数据走势。
- 能耗增速 2023 年后低于产值增速，能源产出率 2025 年达到 3.0 以上。
- 2023 年起绿电交易、2024 年屋顶光伏扩容：可再生能源利用率 2021 年约 1% → 2025 年约 16%。
- 碳排放 2023–2024 年达峰，2025 年较峰值下降。
- 单位增加值 CO₂ 年降 8%–12%，排放弹性系数小于 0.5、最终为负。
- 预算、预警、预测、情景路线图随之重算，预警数量随趋势改善而减少，但保留少量真实感的个别企业超标。

### 实施方式（遵守数据规则）

- 走导入通道，新建导入批次“模拟数据 v2（绿色转型情景）”。
- 旧行 `is_current=false`，不删除。
- 新行仍标 `data_source='estimated'`。
- 重算指标、预警、预测，并运行治理。
