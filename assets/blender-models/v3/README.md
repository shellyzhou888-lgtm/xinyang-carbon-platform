## 本轮修正

1. 按四张 v2 概念图重新组织构图，不再把同一种单体铺成宽间距网格。新构图使用 78 个建筑/组团单元，不是原 148 个复制单元的逐栋对应清单，也不是实测建筑数量。
2. 家居区保留紧凑平行长跨厂房与独立工艺组团；电子区区分前排双厂房、中部预留地、院落及北部蓝顶；北湖以岸线、林地和低密庭院为主；研发区保留前景未开发地与不同建筑组团。
3. 增加主附楼、高低跨、屋顶排跨、退台、侧翼、连廊、管架和塔体。采用不同树冠形态、尺度、色相及林地/行道树种植逻辑，树种未作植物学鉴定。
4. 依据归档实拍解释银灰屋面、灰白墙体、红色装卸口、蓝色金属屋面、暗色玻璃、沥青、枯绿地表与蓝绿色水体。没有把夕照、效果图或未定位楼宇当作本区固有颜色/已建实体。

## 尚未通过的部分

- 林地密实度、地形高差、环境远景和部分立面仍简化，整体仍有沙盘感；不能声称已与概念图完全一致或达到照片级效果。
- 材质为照片观察后的程序化近似，未使用实测反射率、现场扫描、正射影像或经过标定的照片贴图；尺寸、位置和结构补充均待核。
- 未执行全面 BVH 穿插/可通行性认证，内部空间不开放漫游。门窗为外观表达，不代表可通行的布尔开口。
- 本轮没有导出新 GLB、没有替换网站模型、没有宣称用户已经确认外观。

## 复现

所有打开、修改、保存、渲染均经 `scripts/blender-mcp-macos.sh call` 调用真实 Blender MCP；不能离线运行这些 bpy 脚本。详见 `docs/park-modeling-v3-review.md`。重放构建必须从原 v2 总工程另开会话开始，不能直接在已有 v3 场景重复执行。
