# 四园区代表建筑概念资料 v1

2026-10-22。四套代表建筑，各一张六向多视图板和一张四局部细节板，共8张原始PNG、40个子画面。此轮不是园区全部楼栋建模清单。

打开index.html查看每套大图，点击图板打开原尺寸。00-multiview-overview.jpg与00-details-overview.jpg是缩略索引，原始PNG未裁剪或放大。references/保留原始照片与卫星截图，来源和限制见reference-manifest.json。

所有图由内置image_gen生成，记录见generation-prompts.json、projection-revision-prompts.json、detail-generation-prompts.json、generation-outputs.json；选定图板原生尺寸与SHA-256见manifest.json。

当前尚未通过资产评审。缺失背侧面、屋顶与尺寸为推定；科创部落院落为新设计提案，研发资产未核实其在规划片区的位置。图面可能仍有跨视图差异或透视残留，需核对后才能定为ASSET TRUTH；详见review-notes.md。

所有后续建模、工程保存、渲染和导出均通过Blender MCP。先全场景灰模，整体检查后做structural refinement，再细化单体。本轮没有输出模型。
