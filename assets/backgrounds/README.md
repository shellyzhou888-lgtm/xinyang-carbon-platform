## 后续取图标准

优先向羊山新区党委宣传统战部或万华园区索取可用于本平台的原始照片与使用授权。登录页优先选经开区内真实厂区的横向原图，建议至少 2560 × 1440 像素，建筑主体在右侧、左侧留出标题空间。允许在前端叠加深灰渐变以接近参考图质感，但不改变场地结构，也不将信阳国家高新区或豫东南高新区的照片标成“信阳经开区”。取得高清授权图后再制作 WebP 和登录页预览。
