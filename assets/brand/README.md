# 信阳经开区能碳管理平台标识

参考样图的横向排版、绿色小图形与深色粗体风格，设计了独立的“循环圆环 + 向上叶形”标记。圆环表达碳循环与持续管理；叶形表达清洁能源和低碳发展。文字使用平台完整名称，不加入英文副标题。

## 文件

- `logo-horizontal.svg`：浅色背景的主标识，透明底，中文已转为矢量路径。
- `logo-horizontal.png`：主标识的高清透明 PNG（1800 × 392）。
- `logo-preview.png`：主标识放在浅色底上的预览 PNG。
- `logo-horizontal-on-dark.svg`：深色背景用的反白版本。
- `logo-symbol.svg`：图形单独使用，可作头像或图标。
- `logo-symbol.png`：图形的高清透明 PNG（784 × 784）。
- `build_logo.py`：矢量文件的生成脚本；运行时需要 Windows 的微软雅黑粗体及 Python 3.13 的 `fontTools`。

## 使用建议

- 浅色底优先使用主标识；深色底使用反白版本，避免给 SVG 另加底色。
- 主绿色 `#0E9F6C`，叶形浅绿 `#45BD7D`，文字深色 `#1C2928`。
- 横向标识显示宽度建议不小于 240 px；更小尺寸使用独立图形。
- 图形四周保留至少一个叶形宽度的空白，不拉伸、不旋转、不改变字间距。
