# 信阳经开区能碳管理平台标识

标识采用绿色圆角方块底、白色 C 形循环圆环与向上叶形。圆环表达碳循环与持续管理；叶形表达清洁能源和低碳发展。文字使用平台完整名称，不加入英文副标题。网页侧栏与登录页使用同一套配色。

## 文件

- `logo-horizontal.svg`：浅色背景的主标识，透明底，中文已转为矢量路径。
- `logo-horizontal.png`：主标识的高清透明 PNG（1800 × 392）。
- `logo-preview.png`：主标识放在浅色底上的预览 PNG。
- `logo-horizontal-on-dark.svg`：深色背景用的反白版本。
- `logo-symbol.svg`：图形单独使用，可作头像或图标。
- `logo-symbol.png`：图形的高清透明 PNG（784 × 784）。
- `build_logo.py`：矢量文件的生成脚本，并同步网页 `apps/web/public/brand` 中的三个 SVG；运行时需要 Windows 的微软雅黑粗体及 Python 的 `fontTools`。

## 使用建议

- 浅色底优先使用主标识；深色底使用反白版本，避免给 SVG 另加底色。
- 图形底色 `#0E9F6C`，C 字母与叶片 `#FFFFFF`，叶脉透出底色；浅色背景文字 `#1C2928`，深色背景文字 `#F4F8F6`。
- 横向标识显示宽度建议不小于 240 px；更小尺寸使用独立图形。
- 图形已包含内部留白，不再叠加深色底块；不拉伸、不旋转、不改变字间距。
